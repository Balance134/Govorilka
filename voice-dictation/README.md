# Говорилка — голосовая диктовка для Windows

Держишь горячую клавишу — говоришь — отпускаешь. Через пару секунд текст сам
появляется в том поле, где стоял курсор: в браузере, в редакторе, в мессенджере.
Распознаёт Gemini 3.5 Transcribe, поверх работает свой словарь терминов, чтобы
«клоткот» превращался в `Claude Code`, а «эн восемь эн» — в `n8n`.

Приложение живёт в трее, окна в панели задач нет, консоль не открывается.

---

## Что нужно для сборки

- Windows 10 или 11
- Python 3.11 или новее (только на машине, где собираем)
- Ключ Gemini API — https://aistudio.google.com/apikey

На компьютере, где приложение будет работать, не нужно ничего: ни Python, ни
библиотек, ни DLL. Только сам `VoiceDictation.exe`.

## Сборка

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
build.bat
```

Готовый файл — `dist\VoiceDictation.exe`. Его можно скопировать на флешку и
запускать на любом ПК.

Чистая релизная сборка: `build.bat` сам удаляет папки `build` и `dist` перед
запуском, так что отдельных действий не требуется.

Иконки лежат в `assets/`. Если захочется другие цвета — правь `assets/make_icons.py`
и запусти `python assets/make_icons.py`.

## Первый запуск

1. Запусти `VoiceDictation.exe`. Ключа ещё нет, поэтому сразу откроется окно настроек.
2. Вставь ключ Gemini API.
3. При желании поправь словарь и правила замен.
4. Нажми **Сохранить и запустить** — окно спрячется, иконка появится у часов.
5. Встань в любое текстовое поле, зажми **Ctrl+Alt+Space**, скажи фразу, отпусти.

Короткий высокий сигнал — запись пошла. Низкий — запись закончилась, пошла
отправка. Дальше текст вставляется сам.

Горячая клавиша по умолчанию — **Ctrl+Alt+Space**. Меняется в настройках: щёлкни
по полю «Горячая клавиша» и нажми нужное сочетание. Новая комбинация начинает
работать сразу, перезапуск не нужен.

## Как устроен двухслойный словарь

Одного списка терминов мало: для модели это подсказка «такое слово бывает», а не
таблица замен. Поэтому слоя два.

**Слой 1 — словарь терминов.** Уходит в Gemini как `custom_vocabulary` и
подталкивает модель к правильным написаниям. Термины через запятую:

```
n8n, Supabase, pgvector, Vercel, Tailwind, AutoLISP, ComfyUI, LUNEO, Claude Code
```

Жёсткий предел — 1000 терминов, сохранение сверх этого блокируется. Больше 100 —
приложение предупредит: качество распознавания может просесть.

**Слой 2 — правила замен.** Работают уже с готовым текстом, локально и
предсказуемо. Одно правило на строку: слева правильная форма, справа — как это
слышится, через запятую.

```
Claude Code = клод код, клоткот, клод коуд, клауд код
n8n = эн восемь эн, н8н, ноден
Supabase = супабейс, супа база, супер база
pgvector = пг вектор, пиджи вектор
ComfyUI = комфи юай, комфи ui
LUNEO = лунео, люнео
# строки, начинающиеся с решётки, игнорируются
```

Что важно знать про замены:

- регистр при поиске не важен: «КЛОД КОД» тоже станет `Claude Code`;
- подставляется ровно то написание, что слева от `=`;
- длинные варианты применяются раньше коротких, поэтому «клод код» не
  превращается в «Claude код»;
- срабатывает только на целом слове: «ноденом» останется «ноденом»;
- левые части правил автоматически добавляются в словарь терминов — дублировать
  `Claude Code` в двух полях не нужно.

## Где лежат настройки

```
%APPDATA%\VoiceDictation\config.json
%APPDATA%\VoiceDictation\logs\app.log
```

Конфиг не зависит от того, где лежит `.exe`: файл можно перенести в другую папку
или на другой диск, настройки останутся. Ключ API хранится только в этом файле —
в `.exe` он не попадает и в журнал не пишется.

Журнал ротируется: 1 МБ, три файла.

## Как устроена работа с Gemini

Весь обмен с API — в одном модуле `src/gemini/client.py`. Проверено по
официальной документации 28.08.2026
(https://ai.google.dev/gemini-api/docs/transcribe):

```
POST https://generativelanguage.googleapis.com/v1beta/interactions
x-goog-api-key: <ключ>
Content-Type: application/json

{
  "model": "gemini-3.5-transcribe",
  "input": [{"type": "audio", "data": "<base64 wav>", "mime_type": "audio/wav"}],
  "generation_config": {
    "transcription_config": {
      "mode": "smart",
      "custom_vocabulary": ["n8n", "Supabase", "Claude Code"],
      "language_codes": []
    }
  }
}
```

- `mode` передаётся строкой `"smart"`. Поля `timestamp_granularities` и
  `diarization_mode` несовместимы со `smart` и не отправляются никогда.
- `language_codes: []` — автоопределение языка и переключение между языками
  внутри одной фразы. В настройках можно задать языки вручную.
- Аудио — WAV PCM 16 бит, 16 кГц, моно, передаётся прямо в запросе (base64).
  Если запись оказалась больше 15 МБ, она сначала уходит через Files API
  (`/upload/v1beta/files`), а в запрос подставляется `uri`. Для обычной диктовки
  этот путь не задействуется.
- Таймауты: 10 секунд на соединение, 120 на ответ.

Ошибки переводятся в человеческие сообщения в трее: неверный ключ, превышен
лимит, нет сети, речь не распознана и так далее.

## Что делать, если не работает

**Не появляется текст, хотя сигналы звучат.** Скорее всего, окно под курсором не
принимает синтетическую вставку. Попробуй в настройках способ вставки
«Посимвольно». Если и это не помогает — приложение положит текст в буфер обмена и
скажет об этом в уведомлении, вставь руками.

**Ничего не происходит при нажатии клавиши.** Проверь, не занята ли комбинация
другой программой, и назначь другую. Отдельный случай — окно, запущенное от имени
администратора: см. «Ограничения».

**«Микрофон недоступен».** Windows → Параметры → Конфиденциальность → Микрофон:
разреши доступ классическим приложениям. Проверь, что микрофон выбран системным
по умолчанию.

**«Неверный ключ Gemini API».** Ключ скопирован не полностью или отозван.
Открой настройки, нажми «Показать» и сверь.

**Приложение не запускается вторым экземпляром.** Так и задумано: вторая копия
просит первую открыть настройки и закрывается.

Подробности всегда в `%APPDATA%\VoiceDictation\logs\app.log`.

## Ограничения

- Клавиатурный хук не работает поверх окон, запущенных с правами администратора,
  если само приложение запущено без них. Лечится запуском Говорилки от
  администратора.
- Некоторые игры, защищённые поля ввода и окна администратора отвергают
  синтетический ввод — текст туда не вставится ни буфером, ни посимвольно.
- `Ctrl+Alt+Del` и `Win+L` перехватить нельзя: их обрабатывает сама Windows.
  Приложение не даст назначить такие комбинации.
- `Alt+Space` назначить можно, но Windows использует его для системного меню
  окна — приложение предупредит о конфликте.
- Одна unary-отправка — до часа аудио.

## Тесты

Автоматические тесты не требуют Windows и не ходят в сеть:

```
pytest
```

Покрыто: конфигурация и её миграция, разбор словаря и правил замен в обе стороны,
применение замен (регистр, границы слов, кириллица, термины с цифрами, приоритет
длинных вариантов), разбор строки горячей клавиши, сборка тела запроса к Gemini,
разбор ответа и всех типов ошибок, переходы состояний.

### Ручная проверка на Windows

То, что тестами не покрывается, проверяется руками:

1. **Трей.** Запусти `.exe` — иконка у часов, всплывающая подсказка
   «Говорилка — Готов». В меню два пункта: «Настройки», «Выход».
2. **Первый запуск.** Удали `%APPDATA%\VoiceDictation\config.json`, запусти —
   должно открыться окно настроек.
3. **Захват комбинации.** В настройках щёлкни поле горячей клавиши, нажми
   `Ctrl+Shift+F9` — в поле появится `ctrl+shift+f9`.
4. **Диктовка.** Открой Блокнот, зажми хоткей, скажи «привет, это проверка»,
   отпусти. Текст появляется сам, кириллица без искажений.
5. **Словарь.** Скажи «открой клоткот» — в тексте должно быть `Claude Code`.
6. **Подавление клавиши.** В Блокноте зажми хоткей — лишние символы не должны
   набираться.
7. **Автоповтор.** Подержи хоткей 10 секунд — запись должна быть одна, длинная.
8. **Короткая запись.** Нажми и сразу отпусти — уведомление «Слишком короткая запись».
9. **Смена хоткея на лету.** Поменяй комбинацию, сохрани, продиктуй новой —
   без перезапуска.
10. **Второй экземпляр.** Запусти `.exe` ещё раз — второй процесс завершится,
    у первого откроются настройки.
11. **Перенос.** Перемести `.exe` в другую папку — настройки на месте.
12. **Нет сети.** Отключи интернет, продиктуй — «Не удалось связаться с Gemini API»,
    приложение продолжает работать.
13. **Выход.** «Выход» в меню трея — процесса `VoiceDictation.exe` не остаётся в
    диспетчере задач.

## Структура

```
src/config/     конфигурация, словарь, правила замен
src/ui/         окно настроек и виджет захвата комбинации
src/audio/      запись микрофона и звуковые сигналы
src/hotkey/     разбор комбинации и низкоуровневый клавиатурный хук
src/gemini/     единственное место с обращением к API
src/injection/  восстановление фокуса и вставка текста
src/tray/       иконка и меню в трее
src/utils/      журнал, единственный экземпляр, состояния
```
