# Команды для сборки Говорилки

Выполнять на Windows-машине, в папке проекта `voice-dictation`.

## 1. Один раз — окружение

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Сборка .exe

```
build.bat
```

Готовый файл: `dist\VoiceDictation.exe`. Его можно копировать на любой ПК.

## 3. Прогнать тесты (по желанию)

```
pytest
```
