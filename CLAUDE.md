# Говорилка

Портативное Windows-приложение для голосовой диктовки: удержание горячей клавиши
записывает микрофон, Gemini 3.5 Transcribe распознаёт, текст вставляется в
активное поле. Код — в `voice-dictation/`.

Состояние — `СОСТОЯНИЕ.md` (читать первым).

## Правила по коду

- Код и комментарии — по-английски, строки интерфейса — по-русски.
- Обращения к Gemini API живут ТОЛЬКО в `src/gemini/client.py`.
- `mode` в запросе — строка, `"smart"` или `"verbatim"`, выбор за пользователем
  в настройках (решение Balance от 28.08.2026; раньше был жёстко `"smart"`).
  `timestamp_granularities` и `diarization_mode` не отправляются НИКОГДА,
  ни в одном режиме — это правило не смягчалось.
- Конфигурация только в `%APPDATA%\VoiceDictation\`, рядом с `.exe` ничего не пишем.
- Ключ API не логируется, не показывается в ошибках, в сборку не попадает.
- Тесты не требуют Windows и не ходят в сеть: `cd voice-dictation && pytest`.

## Инфраструктура — общая, своей не заводить

Приложение целиком локальное, серверов не требует. Сервер 95
(`cx33-helsinki-prod`) и общий `supabase-db` — если что-то понадобится, только они.
